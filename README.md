# audio-resample

对游戏音频流做分块重采样，只用 Python 标准库。

## 口径

- 输入按任意边界到达，输出采样相位必须跨 chunk 连续。
- 多声道以帧为单位插值，声道不能串线；末尾 flush 要保留可生成的尾帧。
- 比例换算保持单调，采样值采用确定的舍入规则；返回 `work` 为消费的输入帧数。
- 不允许每个 chunk 从零开始建立新的时间轴。

## 不变量

- 输出帧的声道数恒定。
- 输出时间单调，分块与一次性输入结果一致。
- 空 chunk 不改变相位和输出。

## 输出契约

CLI 输出 JSON：`samples` 为交错整数样本，另有 `frames` 与 `work`。
